# 小账本 · BillApp

> 一个简洁的本地记账 Android 应用。支持支出/收入记录、分期记账、Excel 导入导出、数据统计与图表展示。所有数据保存在本地，不联网、无广告、无需登录。

## 功能特性

### 📝 记账

- **支出记账**：常规单笔 + 分期记账（按月分摊，自动生成多期账单）
- **收入记账**：支持所属月份与入账月份分离（跨月归属，如工资次月发放）
- **分类管理**：内置常用分类字典（支出 13 类 / 收入 6 类）
- **快捷备注**：常用备注标签一键填入
- **自定义日期选择**：自研日历控件，界面统一
- **金额输入**：自动清空、失焦恢复、精度处理

### 📋 账单列表

- **支出/收入切换**：首页顶部 Tab 一键切换
- **按月分组**：以「所属月份」为维度分组，跨月归属账单明确标注
- **分页加载**：滚动到底自动加载更多
- **下拉刷新**
- **空状态提示**
- **长按删除**：弹窗二次确认
- **点击详情**：显示完整账单信息

### 📊 数据统计

- **三种视图**：月度 / 年度 / 汇总
- **收支汇总卡片**：收入、支出、结余一目了然
- **结余比例**：显示结余占收入的百分比
- **趋势折线图**：
    - 月度：按天聚合，只画支出线（避免薪资滞后造成的误导）
    - 年度：按月聚合，双线（收入 + 支出）
    - 汇总：按年聚合，双线
    - 支持横向滑动、点击查看具体金额
    - 「含大额」开关：避免房租等大额支出压缩日常消费的可视区间
- **分类排行**：按金额降序，带进度条和百分比
- **支付方式排行**：仅支出视图显示
- **下钻明细**：点击任意分类，底部弹出该分类下所有明细
- **时间翻页**：可翻到数据库中存在账单的月份/年份，边界自动禁用箭头

### 📥 Excel 导入

- **支出导入**：表头 `日期 | 备注 | 分类 | 支付方式 | 金额`，文件名 `yyyy-MM.xlsx`
- **收入导入**：表头 `年月 | 到账日期 | 金额 | 类型 | 备注`
- **批量导入**：支持选择整个文件夹
- **MD5 去重**：同一文件不会重复导入
- **金额精度**：使用 `BigDecimal` 转换，避免浮点误差
- **导入历史记录**
- **月份冲突提示**：已存在数据的月份可选择覆盖或跳过

### 📤 Excel 导出

- **支出导出**：按月导出，支持「消费统计」公式（`SUMIFS`，动态生成）
- **收入导出**：一次性导出全部收入
- **格式与导入对称**：导出的文件可直接用于重新导入
- **自由选择保存目录**（SAF）
- **导出前确认弹窗**

### ⚙️ 其他

- 数据完全本地存储（Room 数据库）
- 数据库索引优化
- 深浅色主题（自动适配系统）
- Edge-to-Edge 全屏适配

## 数据库设计

| 表名 | 用途 |
| :--- | :--- |
| `consume_bill` | 支出账单 |
| `income_bill` | 收入账单 |
| `dict` | 字典（分类、支付方式、备注） |
| `import_file_his` | 导入历史（防重复导入） |

### 核心字段说明

- **金额**：以「分」为单位存储（`Int`），避免浮点误差
- **日期**：`yyyyMMdd` 格式整数（如 `20260927`）
- **所属月份**：`yyyyMM` 格式整数（如 `202609`）
- **账单类型**：`NORMAL`（单笔）/ `INSTALLMENT`（分期）

### 索引设计

| 表 | 索引字段 | 用途 |
| :--- | :--- | :--- |
| `consume_bill` | `BILL_MONTH` | 按月过滤 |
| `consume_bill` | `PAY_DATE` | 按日期排序 |
| `consume_bill` | `BILL_MONTH, CATEGORY_ID` | 分类统计 |
| `consume_bill` | `BILL_MONTH, PAY_CHANNEL_ID` | 支付方式统计 |
| `income_bill` | `BILL_MONTH` | 按月过滤 |
| `income_bill` | `POST_DATE` | 按日期排序 |
| `income_bill` | `BILL_MONTH, CATEGORY_ID` | 分类统计 |
| `import_file_his` | `FILE_MD5, IMPORT_TYPE` | 文件去重 |

## 构建与运行

### 环境要求

- Android Studio Hedgehog (2023.1) 或更高
- JDK 17
- Android SDK 34

### 克隆与构建

```bash
git clone <repository-url>
cd BillApp
./gradlew assembleDebug
```

APK 生成位置：`app/build/outputs/apk/debug/app-debug.apk`

### 安装

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

## Excel 模板说明

### 支出导入模板

| 日期 | 备注 | 分类 | 支付方式 | 金额 |
| :--- | :--- | :--- | :--- | :--- |
| 2026-09-06 | 晚饭 | 餐饮美食 | 支付宝 | 45.00 |
| 2026-09-05 | 房租 | 住房物业 | 银行卡 | 1500.00 |

**约束：**
- 文件名必须为 `yyyy-MM.xlsx` 或 `yyyy-MM.xls`
- 表头必须完全匹配（顺序不能变）
- 金额列为数字类型

### 收入导入模板

| 年月 | 到账日期 | 金额 | 类型 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| 2026-08 | 2026/09/05 | 11240.57 | 工资 | 2026年08月工资 |
| 2026-09 | 2026/09/15 | 5000.00 | 奖金 | 季度奖金 |

**约束：**
- 「年月」使用 `yyyy-MM` 格式
- 「到账日期」使用 `yyyy/MM/dd` 格式
- 「类型」必须能在收入分类字典中匹配

### 支出导出格式

导出的 `yyyy-MM.xlsx` 包含：

- **A~E 列**：账单数据（表头与导入模板一致）
- **G~H 列**：消费统计区（`SUMIFS` 公式，动态从字典生成）

统计区包含：
- 总消费
- 各支付方式消费（支付宝、微信、银行卡……）
- 各分类消费（餐饮美食、交通出行……）

> ⚠️ 公式依赖 Excel/WPS 打开时自动重算，手机端简易阅读器可能不显示结果。

### 收入导出格式

一次性导出全部收入，文件名为 `收入数据-截止yyyyMMdd.xlsx`，5 列数据，无统计区。

## 已知限制

### v1.0 现状

- 暂不支持账单编辑（仅删除）
- 分类/支付方式暂不支持用户自定义
- 暂不支持数据云同步
- 备份恢复功能待实现
- 搜索功能待实现
- 「关于」页面待实现
- 「我的」页面部分菜单点击无响应

### 待修复缺陷

| 缺陷 | 影响 | 状态 |
| :--- | :--- | :--- |
| **手动记账金额精度问题** | 输入 `9.7` 等小数时，`(Double * 100).toInt()` 会因浮点误差少 1 分（显示 `9.69`） | 🔴 待修复 |
| 底部导航栏不同设备表现差异 | 真机与模拟器显示高度不一致 | 🟡 观察中 |
| 状态栏配色不一致 | 部分设备状态栏仍显示系统主题色 | 🟡 观察中 |

> **金额精度问题修复方案**：将 `(amountYuan * 100).toInt()` 改为 `BigDecimal` 计算（与导入逻辑保持一致）。涉及 `AddExpenseDialogFragment`（2 处）和 `IncomeAddDialogFragment`（1 处）。
